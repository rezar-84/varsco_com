| ADR-006 | Zod input schema validations                                 | Neutralizes malformed payloads and injection threats at the Astro/Start BFF entry points prior to querying Odoo.                                                                                                                                                                                                                                                                                                                                                                                            | Accepted |
| ADR-007 | Ignored environment variables (`.env`)                       | Restricts credentials to `.env` which is excluded from Git to prevent security leaks, utilizing `.env.example` as configuration templates.                                                                                                                                                                                                                                                                                                                                                                  | Accepted |
| ADR-008 | Real-geometry SVG maps sourced from public boundary datasets | Replaced hand-drawn placeholder country/province outlines (Türkiye About Us map, Middle East corridor map) with geographically accurate paths derived from Wikimedia Commons ("Turkey provinces blank.svg", CC BY-SA 3.0) and the `djaiss/mapsicon` country-silhouette dataset, reprojected to equirectangular canvases calibrated against each region's real lon/lat bounding box. Chosen over hand-tuned SVGs because pin placement and boundary shape must both be trustworthy for a B2B trade-hub site. | Accepted |
| ADR-009 | `Documents/VARS/blogimages` scoped to in-body content images only | A prior session repurposed images from this folder as blog post *cover* images, overwriting the real per-post covers from varsco.com. User clarified the folder was provided only for images referenced inside blog post bodies; covers must come from the live site and this folder must never be used as a cover-image source again. | Accepted |
| ADR-010 | No fabricated statistics or named-country sourcing/shipping claims in marketing copy | Copy stated specific unverifiable facts (a "10+ countries / weekly shipments" stat, "Europe and Iceland" as named origin countries, a fixed "ADB/IST to DXB/ICN" shipping route) that don't reflect the actual variable, multi-origin/multi-destination business. Replaced with defensible capability language (multi-origin, global shipping) with no invented numbers; the origin/shipping illustrations were redesigned as generic globes rather than fixed-point diagrams so they never assert routes/origins the business can't guarantee. | Accepted |
| ADR-011 | Neutral use-case framing for pages comparing two VARS product lines | The Decapsulated-vs-Standard Artemia guide argued decapsulated Artemia "outperforms"/is the "ultimate alternative" to standard cysts, but VARS sells both. Any future page comparing two VARS-sold products should present a neutral feature comparison plus use-case guidance per customer segment, not a "which one wins" framing that undercuts one of the company's own product lines. | Accepted |
